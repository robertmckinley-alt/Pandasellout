# Bamboo Sellout Intelligence

A standalone, eight-week wholesale allocation analysis for Rob. Its own private GitHub repository and Vercel project are separate from Bamboo SKU Intelligence.

The main question is which products exhaust their weekly allocation, how often it repeats, and whether allocation size explains the result. Track by product_id. Show observed figures, coverage, and limitations beside interpretations. Weekly wholesale order data cannot prove day of sellout, consumer retail stockouts, lost sales, or optimal price/production changes.

Approved scope: audited data; responsive charts, heatmap, ranked table, product details, week/brand/category/search/history/frequency filters; CSV, detailed Excel, and PDF; Git history; Vercel deployment; repeatable weekly refresh; end-to-end verification.
