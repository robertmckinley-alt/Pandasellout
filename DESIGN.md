# Dashboard design

Mode: Operate. The audience uses the dashboard for weekly supply review on desktop, with mobile access for checking individual products.

Use a light analytical workspace, emerald/slate palette, clear numerals, restrained borders, accessible contrast and keyboard focus. Keep visual priority on product names, sold-out weeks / offered weeks, allocation quantities, and eight-week patterns. Exact sellout and near-sellout are separate text-labeled states; absence is never a failed sale. Charts use consistent units, explicit denominators and full accessible titles. Filters update linked views; downloads name their scope. A product drilldown shows source figures. No unsupported numeric price or production recommendations.
